1
注册 Kakao 开发者账号
先有账号，才能创建 App 和 Bot
  1. 打开 https://developers.kakao.com，用你的 KakaoTalk 账号登录
  2. 点击右上角 내 애플리케이션（My Applications）
  3. 点击 애플리케이션 추가하기（添加应用）
  4. 填写 App Name（随便填，比如 MyBot）和公司名（个人用填自己名字就行）
  5. 点击 저장（保存）
✅
完成后会得到一个 앱 키（App Key），先记下来备用。
2
创建 KakaoTalk 频道 카카오 채널
Bot 必须绑定在频道上，相当于微信公众号
  1. 打开 https://center-pf.kakao.com
  2. 点击 채널 만들기（创建频道）
  3. 填写：
    • 채널 이름（频道名称）：你 Bot 的名字
    • 검색용 아이디（搜索ID）：唯一标识，字母+数字
    • 카테고리（分类）：随便选一个就行
  4. 点击 개설（创建）
  5. 左侧找到 채널 공개 설정（频道公开设置）
    → 建议先设为 비공개（不公开），测试完再改
⚠️
新频道需要等待审核，通常几分钟到几小时不等，耐心等一下。
3
在 Open Builder 创建 Chatbot
Bot 的大脑在这里配置
  1. 打开 https://i.kakao.com（Kakao i Open Builder），用 Kakao 账号登录
  2. 点右上角蓝色 ➕ 按钮，再选左侧两个气泡的图标
  3. 填写 Bot 名称，点 확인（确认）
  4. 进入 Bot 编辑页面 → 点左侧 설정（设置图标）
  5. 找到 채널 연결（连接频道），选择刚才创建的频道连接
4
配置 Skill —— 你的 Webhook API 스킬
核心步骤！Skill = 你自己服务器上的接口
  1. 左侧点击 스킬（技能）→ 스킬 추가（添加技能）
  2. 填写 Skill 名称，服务器地址填你的 API 地址（必须 HTTPS！），超时时间设 5000ms（Kakao 限制最大 5 秒）
  3. 左上角小框勾选，点蓝色按钮保存
  4. 点 스킬 서버 확인（检查 Skill 服务器），确保你的服务器能响应
💬
如果用的不是特别快的模型，建议打开回调：
시나리오 > 폴백 블록 > 左上角三个点 > callback > 打开保存
不需要写任何文字，打开就行，否则每条回复前都会带上你填的那段文字。打开回调后，记得在 VPS 上写回调处理代码～
KakaoTalk 发给你的请求格式
request.json 
{
  "intent": {
    "id": "xxxxx",
    "name": "폴백 블록"
  },
  "userRequest": {
    "utterance": "用户说的话在这里",
    "user": {
      "id": "用户唯一ID",
      "type": "botUserKey"
    },
    "callbackUrl": "开了回调才会有此字段"
  },
  "bot": {
    "id": "你的botID",
    "name": "Bot名称"
  }
}
你的 API 需要返回的格式
response.json 
{
  "version": "2.0",
  "template": {
    "outputs": [
      {
        "simpleText": {
          "text": "这里是 Bot 回复的内容"
        }
      }
    ]
  }
}
5
绑定 Skill 到 Fallback Block 폴백 블록
用户发任意消息都会触发，是接 API Bot 的关键

按照以下路径操作：

시나리오 → 폴백 블록 → 最下面的 + 응답 추가 → 选 《》스킬데이터 → 蓝色按钮保存

6
部署你的 API 服务器
下面是 Python + Flask 最简可用示例，支持回调模式
app.py 
from flask import Flask, request, jsonify
import requests, threading

app = Flask(__name__)

CLAUDE_API_KEY = "你的API密钥"
FAIL_TEXT = "我有事，等会说"  # 模型出错时回这句

def reply_json(text):
    # simpleText 单气泡最多 1000 字，超了 Kakao 会拒收
    return {
        "version": "2.0",
        "template": {
            "outputs": [{
                "simpleText": {"text": (text or FAIL_TEXT)[:1000]}
            }]
        }
    }

def call_ai(message, timeout):
    try:
        r = requests.post(
            "https://api.anthropic.com/v1/messages",
            headers={
                "x-api-key": CLAUDE_API_KEY,
                "anthropic-version": "2023-06-01",
                "content-type": "application/json"
            },
            json={
                "model": "claude-sonnet-5",
                "max_tokens": 1024,
                "messages": [{"role": "user", "content": message}]
            },
            timeout=timeout
        )
        return r.json()["content"][0]["text"]
    except Exception as e:
        print("AI 调用失败:", e)
        return FAIL_TEXT

@app.route('/kakao/webhook', methods=['POST'])
def kakao_webhook():
    data = request.get_json(silent=True) or {}
    ur = data.get("userRequest", {})
    user_message = ur.get("utterance", "")
    callback_url = ur.get("callbackUrl")  # 开了回调才有

    if callback_url:
        # 回调模式：先告诉 Kakao「等一下」，后台慢慢生成，最多 1 分钟
        def work():
            text = call_ai(user_message, timeout=50)
            requests.post(callback_url, json=reply_json(text), timeout=10)
        threading.Thread(target=work, daemon=True).start()
        return jsonify({"version": "2.0", "useCallback": True})

    # 同步模式：必须 5 秒内回
    return jsonify(reply_json(call_ai(user_message, timeout=4.5)))

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
部署到 VPS
bash 
pip install flask requests
python app.py
🔒
Open Builder 必须使用 HTTPS！ 本地或 HTTP 地址一律不接受。用 Nginx + Let's Encrypt 配置 SSL：
nginx 配置 
# 安装证书
sudo apt install nginx certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com

# 在 /etc/nginx/sites-available/default 的 443 server {} 里加：
location /kakao/ {
    proxy_pass http://127.0.0.1:5000;
}

# 重载
sudo nginx -t && sudo systemctl reload nginx
7
测试 & 部署上线 배포
改动完了一定要部署，不然没用！
  1. Open Builder 右上角点 배포（部署）→ 배포하기（立即部署）
  2. 打开 KakaoTalk，搜索你的频道名称
  3. 关注后发一条消息，看看 Bot 是否正常回复 🎉
💡
改了 VPS 上的代码，不需要重新部署。只要在 Open Builder 网页内有改动，才需要重新部署。
没有回复？按顺序排查
  1. 你的服务器是否在运行（本地 curl 测试一下）
  2. Open Builder 的 Skill 检测是否通过
  3. 频道和 Bot 是否正确连接
  4. 폴백 블록 是否绑定了 Skill
🤔
常见问题
Skill 检测一直失败？
确保你的服务器地址是 HTTPS，且能公网访问。Open Builder 不接受 HTTP 或 localhost。
消息发出去没有回复？
检查 폴백 블록 是否绑定了 Skill，以及 Bot 是否已经「배포（部署）」。
想要支持图片/按钮等富文本？
outputs 里把 simpleText 换成 basicCard 或 listCard，具体格式见官方文档：https://i.kakao.com/docs/skill-response-format
有没有多轮对话支持？
KakaoTalk 不传历史记录，需要你自己在服务器端用 user.id 作为 key，维护对话历史（作者目前注入上下文 12 条）。
